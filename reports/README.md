# Reports

This directory is a place to store the final written deliverables for
academic submission, such as:

- The final project report / documentation (PDF or Word)
- A presentation slide deck, if required separately from `docs/`
- Any supervisor feedback or evaluation sheets

No report has been generated automatically, since its content (team
details, evaluation criteria, submission formatting) is institution- and
course-specific and has not been provided. Add your finished report(s)
here before submission.
