# Data

This project does not require any external dataset.

It demonstrates operating-system process management concepts (creation,
execution, identification, synchronization, and termination) using live
calls to the Linux kernel via POSIX system calls. All of its "input" is
the process state the kernel reports at runtime (PIDs, PPIDs, exit
statuses) and, optionally, a command typed by the user for option 2
("Execute Program").

This directory is kept in the project structure for completeness and to
hold any small, non-sensitive sample input files, if they ever become
necessary. It is currently empty by design.
